# When Love Responds — 통합 전시 갤러리

여섯 가지 사랑(EROS · LUDUS · PHILIA · STORGE · PRAGMA · AGAPE)을 한 화면에 모아 자유롭게 선택하는 전시용 메인 웹사이트입니다.
빌드 과정이 없는 정적 사이트라서 Vercel에 그대로 올리면 됩니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `works.js` | **작품 주소·이름·설명·크기 보정값** — 수정할 일이 있으면 이 파일만 고치면 됩니다 |
| `index.html` / `styles.css` / `app.js` | 갤러리 화면과 동작 |
| `assets/works/*.webp` | 렌더 PNG를 투명 영역만 잘라 최적화한 이미지 (720px / 1400px 두 크기) |
| `exhibition/전시 시작.command` | 맥북에서 더블클릭 → 크롬 키오스크 모드로 갤러리 실행 |
| `exhibition/전시 종료.command` | 전시용 크롬만 종료 |

원본 렌더 PNG(약 68MB)는 사이트에 포함하지 않고 그대로 보존했습니다. 사이트용 이미지는 6장 합쳐 약 0.6MB(1400px 기준)입니다.

## 작품 연결 방식

- **기본값 `openMode: 'frame'`** — 작품을 갤러리 안에서 화면 전체로 띄웁니다.
  - 주소가 바뀌지 않으므로 **전체화면이 풀리지 않습니다**.
  - 왼쪽 아래에 `BACK TO GALLERY` 버튼이 자동으로 붙습니다 → **개별 작품 코드는 수정할 필요 없음**.
  - 갤러리로 돌아오면 작품을 완전히 종료(마이크·소리 정지)합니다.
  - 각 작품은 실시간 주소를 그대로 불러오므로, 개별 사이트를 수정·재배포하면 즉시 반영됩니다.
- `openMode: 'link'` — 작품 주소로 직접 이동합니다. 이 경우 작품 쪽에 돌아오는 버튼이 따로 필요합니다(아래 참고).
- 주소 뒤에 `?mode=link` / `?mode=frame`을 붙이면 설정을 바꾸지 않고 임시로 전환할 수 있습니다.

## 전시장 설치 (맥북 + 크롬)

### 가장 안정적인 방법 — 키오스크 모드 (권장)
1. `exhibition/전시 시작.command`를 텍스트 편집기로 열어 `GALLERY_URL`을 실제 배포 주소로 바꿉니다. (주소 끝의 `?kiosk`는 남겨 두세요 — ENTER EXHIBITION 버튼을 숨깁니다.)
2. 처음 한 번은 파일을 **우클릭 → 열기**로 실행합니다(맥 보안 확인). 이후로는 더블클릭.
3. 크롬이 주소창·탭 없이 전체화면으로 열립니다.
   - 평소 쓰는 크롬과 분리된 **전시 전용 프로필**로 열리므로 북마크·로그인 정보가 노출되지 않습니다.
   - 마이크·카메라 허용 창이 뜨지 않도록 자동 허용됩니다.
   - 작품을 오가도 키오스크 상태가 유지되므로 다시 누를 버튼이 없습니다.

### 버튼으로 들어가는 방법
- 일반 크롬에서 갤러리를 열고 오른쪽 아래 `ENTER EXHIBITION`을 누르면 전체화면이 됩니다.
- frame 방식에서는 작품을 오가도 전체화면이 유지됩니다.
- 단, 페이지를 새로고침하면 브라우저 정책상 전체화면이 풀립니다 → 전시 운영에는 키오스크를 권장합니다.

### 크롬 자체 전체화면 (명령 파일 없이)
- 크롬 메뉴 `보기` → **`전체 화면에서 항상 툴바 표시` 체크 해제** → `⌃⌘F`
- 페이지를 이동·새로고침해도 유지되지만, 마우스를 화면 맨 위로 올리면 주소창이 내려올 수 있습니다.

### 맥북 설정 체크리스트
- 시스템 설정 → 잠금 화면 / 디스플레이: **화면 꺼짐·잠자기 안 함**
- 시스템 설정 → 알림: **방해금지 모드 켜기**
- Dock 자동 숨기기, 외부 모니터 사용 시 해상도 1920×1080 확인
- 전원 어댑터 연결, Wi-Fi 안정성 확인

### 종료 · 관리자 조작
| 동작 | 방법 |
|---|---|
| 전시 화면 종료 | `⌘Q` 또는 `exhibition/전시 종료.command` 더블클릭 |
| 갤러리로 강제 복귀 | `BACK TO GALLERY` 버튼, 또는 `⌘[` (브라우저 뒤로) |
| 새로고침 | `⌘R` |
| 버튼 방식 전체화면 해제 | `esc` |

## 작품 쪽 수정이 필요한 경우 (선택)

**frame 방식에서는 수정이 필요 없습니다.** 아래는 필요할 때만 참고하세요.

1. **작품이 iframe 표시를 막는 경우** — Vercel 기본 설정은 막지 않지만, 작품의 `vercel.json`에 `X-Frame-Options` 또는 `Content-Security-Policy: frame-ancestors`가 있다면 갤러리 주소를 허용해야 합니다.
2. **작품 안에 자체 돌아가기 버튼을 넣고 싶을 때** — 작품 코드에서 아래 한 줄을 실행하면 갤러리가 닫아 줍니다.
   ```js
   window.parent !== window && window.parent.postMessage('wlr:back-to-gallery', '*');
   ```
3. **link 방식을 쓸 때** — 작품마다 `BACK TO GALLERY` 링크(갤러리 주소)를 추가해야 합니다.
